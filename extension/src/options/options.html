设置

第一次用：按 ① ② ③ 填完，点最下面的「保存全部设置」，再去侧边栏点「开始」。后面几块有默认值，不改也能用。

①模型 Key（DeepSeek）

筛岗位、写开场白、解析简历都要用模型。去 platform.deepseek.com 注册、充值（10 元能用很久），在「API keys」里创建一个，粘到下面，点「测试连接」。 Key 只存在你这台电脑的浏览器里，不会发给别人。按 DeepSeek 官方价估，筛一个岗位大约一两分钱。

换别的模型（一般不用动）

接口地址换成 DeepSeek / Claude 以外的，保存时浏览器会弹窗问你要不要给这个网站的访问权限，点允许。

②求职城市

城市代码查不到时手填

在 BOSS / 51job 网站上选好城市搜一次，地址栏里 city= / jobArea= 后面那串数字就是代码。

③简历

把简历全文粘进来（Word / PDF 里全选复制即可），点「解析简历」，模型会拆成下面的格子。 解析只是照抄和归类，不会替你润色或编造；读错的直接在格子里改。

找工作标准

模型按这段话判断每个岗位「投 / 等你定 / 不投」。把带【】的地方改成你自己的情况，不需要的段落直接删； 写得越具体，筛得越准。

硬性筛选

本地跑，不花钱。在这一步淘汰掉的岗位不会调用模型。列表页薪资是防爬字体读不出来，薪资条件在打开详情页后才生效。

简历变体（可选）

BOSS 的附件简历绑在账号上，工具没法逐岗位自动换。如果你在 BOSS 上传了 2~4 份不同侧重的简历， 在这里登记，工具评估岗位时会告诉你「这个该发哪一份」。只传了一份就不用管。

进列表的门槛

不会自动投：筛选只把结论不是「不投」的岗位排进列表，你按「投」才发。 模型判「等你定」的不管多少分都进列表；判「投」但匹配分低于这条线的不进列表。

节奏与配额

BOSS 对打招呼频率有限制，短时间大量操作会触发验证码甚至限号。 下面这组默认值是偏保守的，建议别往激进了调。

开场白

不管模型写成什么样，发之前都会再查一遍：问底薪、休息的句子删掉；出现禁用词的不发，转到待确认。

网申自动填（可选）

在公司官网的网申表单页，侧边栏「网申」里点「填这一页」会按你的简历填表（只填不交）。下面两个文件用来自动上传附件，不填就你自己传。
