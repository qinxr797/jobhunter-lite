# 求职助手 v1.0.0

一个 Chrome 插件。它会在 BOSS直聘、前程无忧（51job）、智联招聘上，按你的简历和求职标准一家家看岗位，判断投不投，再替你写好开场白。结果排成一张清单，**你按了「投」它才会发**。

## 安装（2 分钟）

1. 在本页点绿色的「Code」→「Download ZIP」下载，解压到一个固定的位置，比如 `D:\求职助手`。装好以后这个文件夹别删，也别挪。
2. 在 Chrome 地址栏打开 `chrome://extensions`，打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选解压出来的 `extension` 文件夹。
4. 点工具栏上的拼图图标，把「求职助手」固定到工具栏。之后点它的图标就会打开侧边栏。

## 第一次用（设置页会自动弹出来）

1. **① 填 Key**：去 platform.deepseek.com 注册账号、充 10 元，创建一个 API Key 粘进来，点「测试连接」。
2. **② 填城市**：填你要找工作的城市，比如「杭州」。
3. **③ 解析简历**：把简历全文复制进来，点「解析简历」。解析出来的格子里有读错的，直接改。
4. 「找工作标准」里带【】的地方，改成你自己的情况。
5. 点最下面的「保存全部设置」。

## 每天用

1. 先在这个 Chrome 里登录 BOSS直聘、51job、智联招聘。
2. 打开侧边栏，在「今天」页点「开始」。插件会自己打开搜索页一家家看，只看不点。筛的时候 Chrome 窗口别最小化。
3. 去「待审」页看结果。开场白可以改，满意的按「投」。

## 要知道的几件事

- **点「投」那一下，BOSS 会先自动发出你账号里设置的默认招呼语**，插件再接着发它写的开场白。所以先去 BOSS 把默认招呼语改成你能接受的。
- 有封号风险，默认设置是保守的：每天最多 15 个，每发一个间隔 25～70 秒，出现验证码就停。这几个数别往大了调。
- 花费：用 DeepSeek，筛一个岗位大约一两分钱。这是按官方价估的。
- 模型的判断只是参考。公司靠不靠谱，投之前自己再看一眼，侧边栏里的「查公司」能帮你查。
