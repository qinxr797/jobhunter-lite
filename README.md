# 求职助手 v2.0.0

一个 Windows 桌面软件，把找工作这件事收进一个窗口：

- **今天**：今天该办的事：HR 约面、要你回的消息、过期没跟进的。
- **投递**：投过的每一家到哪一步了，所有平台合成一张表。
- **消息**：BOSS 直聘、智联、猎聘的 HR 消息集中在一处，AI 帮你起草回复，你确认了再发。
- **找岗位**：按你的简历和求职标准，到 BOSS、51job、智联去筛岗位。结果排成清单，你按了「投」才会发。
- **网申**：打开公司官网的网申表，一键把简历内容填进去；最后的「提交」由你自己点。

后台一直盯着各平台的新消息，遇到约面这类事会提醒你。

> 旧版（只有 Chrome 插件的 v1.1.0）在 [v1 分支](../../tree/v1)，还能照旧下载。

## 安装（2 分钟）

1. 到右边 **Releases** 下载 `jobhunter-v2.0.0-win64.zip`，解压到一个固定的位置，比如 `D:\求职助手`。之后这个文件夹别删、别挪。
2. 双击 `HR Desk\HR Desk.exe`。第一次打开会在桌面放一个「求职助手」图标，以后双击它就行。
3. 电脑里要有 **Chrome 或 Edge**（Win10 / 11 自带 Edge）。找岗位和网申要借用它。

## 第一次设置（3 分钟）

打开后先出来的是设置页。带 1～3 的必须填：

1. **DeepSeek API Key**：去 platform.deepseek.com 注册，充 10 元，创建一个 Key 粘进来，点「测试连接」。
2. **城市、一句话介绍自己、想找的岗位**。
3. **简历**：全文粘贴进来就行。

其余的以后在「更多 › 设置」里补。

然后在 **更多 › BOSS 直聘 / 智联 / 51job / 猎聘** 里各扫码登录一次，别的地方都不用登。插件不用往 Chrome 里装，后台会自己装好。

## 要知道的几件事

- 所有东西都存在你自己电脑上（安装目录下的 `data` 文件夹），不会上传到任何服务器。AI 判断时会把岗位信息和你的简历发给 DeepSeek。
- 有封号风险。默认设置是保守的：每天最多打 15 个招呼，每发一个间隔几十秒，出现验证码就停。别把这些数往大了调。
- 花费：用 DeepSeek 筛一个岗位大约一两分钱（按官方价估算）。
- AI 的判断只能当参考。公司靠不靠谱，投之前自己再看一眼。
