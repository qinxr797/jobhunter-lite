# watcher：桌面助手的后台

盯梢（自动看 BOSS / 智联 / 51job / 猎聘的 HR 消息、按你的设置回复）、收件箱网页（127.0.0.1:8790）、投递总表、「找新岗位」多来源扫描都在这里。平时不用手动开：桌面助手启动时会自动拉起它。

## 设置

都在 `<安装目录>\data\config.json`，第一次打开桌面助手时设置向导会替你写好。字段说明见 `config.example.json`，常用的几项：

- `deepseek.apiKey`：自动回复、起草、筛岗位都要用（必填）
- `city`、`resumeText`：找工作的城市、简历全文（必填）
- `criteria`：求职标准，比如「双休、不做销售电销」，自动回复按它判断
- `blacklist`：拉黑的公司关键词，不回、不推、不投
- `wechatAlt`：HR 要微信时给的号；空着就交给你本人
- `telegram`：填了 token 和 chatId，约面试这类消息会推到手机

改完不用重启，下一轮自动读新的。

## 数据

全部在 `<安装目录>\data\watcher\`（状态、日志、聊天快照、投递总表 tracker.db、插件后台浏览器的资料）。换电脑把整个 `data` 文件夹带走就行。

## 求职插件在哪跑

找岗位、网申公告、岗位评分要调求职插件。插件跑不进桌面助手，所以 watcher 会在后台开一个看不见的 Chrome（没有就用 Edge）把 `extension\` 装进去，端口每次自动挑空闲的。两个浏览器都没有时，这几项会灰掉，并提示怎么装。
